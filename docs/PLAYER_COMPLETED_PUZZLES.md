# 플레이어별 완료 퍼즐 ID 인덱스 (2026-11-10)

## 적용된 구조

- **공용 퍼즐별 플레이어 목록은 만들지 않는다.**
- **로그인 플레이어:** Firebase Realtime Database `userCompleted/{uid}/{puzzleId} = 완료 시각(서버 시간)`
- **비회원:** 브라우저 `localStorage`의 `nono-completed-puzzles-v1:guest`에 퍼즐 ID별 완료 시각 기록
- 로그인 계정별 브라우저 임시 인덱스: `nono-completed-puzzles-v1:{uid}`
- 완료한 같은 퍼즐은 모드(혼자/대결/협동)에 관계없이 한 ID로 합친다.
- *완료*가 확인된 이후에만 기록한다. 시작·중도 종료·이어 풀기는 경험으로 계산하지 않는다.
- 기존 `nono-completion-history-v1`에 남아 있는 과거 완료 기록을 초기에 ID 인덱스로 합친다. 과거 완료 기록 자체가 잘려 있으면 되살릴 수 없다.
- 정식 로그인 전환 시 비회원 완료 ID를 로그인 계정으로 병합한다. 다른 계정끼리는 완료 목록을 섞지 않는다.
- 클라우드 접근은 자신의 UID에만 가능하고, 개별 퍼즐의 기록은 한 번만 추가할 수 있다. 다른 사용자의 목록 접근, 삭제·덮어쓰기를 금지한다.
- Firebase 인증 계정만 클라우드 동기화한다. 비회원은 브라우저에만 저장된다.
- 미완료 게임 저장·재개 시스템은 변경하지 않았다.

## 완료 알림 연결

- 기존 `nono:completion-confirmed`는 정식 혼자 풀기, 대결, 협동 완료 시 완료 ID를 기록한다.
- 로컬 체험용/랜덤 퍼즐의 혼자 풀기 완료는 `nono:private-puzzle-completed`를 새로 전달한다. **개인 완료 인덱스에만 반영하며 최근 공개 완료 피드나 포인트 지급 여부는 바꾸지 않는다.**
- 협동은 현재 게임 코드가 완료 이벤트를 전달하는 참여자의 기록에 추가된다. 전체 참여자 공동 완료 인정은 별도의 게임 정책/서버 확인이 필요하다.
- `nono-completion-history-v1`는 최근 완료 UI/기존 계정 동기화 용도다. 이 기록의 최대 건수 제한을 완료 ID 인덱스에 적용하지 않는다.

## 접근 API

`window.NONO_COMPLETED_PUZZLES`:

- `has(puzzleId)`: 현재 사용자 완료 여부
- `all()`: `{puzzleId: 완료시각}` 객체 복사
- `completedCount()`: 서로 다른 완료 퍼즐 ID 수
- `unseen(puzzles)`: 퍼즐 ID 문자열 또는 `{id}` 목록에서 현재 사용자 미완료 목록만 선택
- `await ready()`: 로그인 계정이면 서버 기록을 읽고 로컬 완료 ID와 합친다. 네트워크 실패 때는 브라우저 데이터 유지

*중요:* 이 API는 완료 기록을 조회·동기화하는 기능이다. 아직 공용 랜덤 퍼즐 재고나 자동 퍼즐 배정 엔진에 연결되지 않았다.

## 보안 및 기능 경계

- 사용자별 완료 ID는 **처음 보는 퍼즐 선택용 개인 인덱스**다. 브라우저에서 발생한 완료 이벤트를 근거로 기록하므로, 이 자체가 서버가 검증한 게임 클리어/포인트 지급 증거는 아니다. 서버 보상·랭킹은 기존 검증 절차 유지.
- 별도의 공용 퍼즐 재고 자동 생성·충전, 대결/협동에서 전체 참가자의 미완료 퍼즐 교집합 선택, 퍼즐 서버 배정 기능은 **아직 구현하지 않았다.**
- 다른 사용자의 완료 목록을 클라이언트에서 읽지 않도록 Firebase 규칙을 둔다. 나중에 공용 퍼즐 매칭 시에는 서버가 참가자들의 목록을 비교해야 한다.
- GitHub에 규칙이 올라간 것과 운영 Firebase에 실제로 배포된 것은 다르다. **운영 Realtime Database 규칙 배포를 별도로 확인해야 클라우드 동기화가 작동한다.**

## 검증

- `tests/completed-puzzles.cjs`: Chromium에서 모드 간 중복 제거, 체험 완료, 중도 시작 제외, 리로드 유지, 비회원→계정 병합, 계정 간 격리.
- `tests/user-completed-rules.cjs`: Firebase 에뮬레이터에서 소유자만 읽기/쓰기, 추가만 가능, 타인·비회원 접근 금지, 다건 추가.
- `.github/workflows/completed-puzzles.yml`: 전체 자동 검사.
