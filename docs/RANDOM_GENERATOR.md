# 랜덤 노노그램 생성 v5 — 유일해 검증 필수 (2026-11-03)

## 생성 규칙
- 특정 그림·도형 없이 **검은 칸의 위치를 무작위 배치**한다. 기존 v4의 무작위 셔플을 사용하고, 검은 칸 목표 비율은 47~53%다.
- 0 힌트를 제외하기 위해 무작위로 열을 섞어 매 행·열에 최소 한 칸씩 둔다. 따라서 아무 조건 없는 균일한 이진 격자 표본은 아니다.
- 검은/흰 비율 지표는 `B=4*b*w/(b+w)^2`를 사용한다. 이 값만으로 재미도나 난이도를 평가하지 않는다.
- 사용자 풀이 데이터 및 논문식 F(`k,u,d,g`)는 사용하지 않는다.

## 유일해 보증 방식
- v5는 **새로 생성한 퍼즐의 행·열 힌트를 대상으로 독립적인 솔버가 가능한 정답을 최대 2개까지 탐색한다.**
- 행·열의 모든 합법적 배치를 제약 전파한 뒤, 미확정 칸에 0 또는 1을 가정하며 탐색한다. 두 개의 해를 찾으면 `multiple`, 정확히 하나를 찾고 탐색을 끝내면 `unique`.
- 탐색 횟수·줄 검사 횟수 제한에 도달하면 `unknown`; **`unknown`은 유일해를 보증하지 않으므로 등록·저장하지 않는다.** `invalid`나 `multiple`도 등록하지 않는다.
- 불합격 시 새 시드의 무작위 칸 배치를 일정 횟수 재생성한다. 재시도 회수와 탐색 예산은 크기에 따른 고정값을 사용한다. 전부 실패하면 **오류를 표시하고 퍼즐을 만들지 않는다.** 이는 퍼즐의 유일해를 우선하기 위한 조치다.
- 같은 `size + difficulty + seed + version`은 같은 시드 시퀀스와 탐색 예산을 사용하므로, 혼자하기/대결/협동이 같은 정답·힌트를 재구성한다.
- **유일해 보증은 v5 퍼즐이 성공적으로 생성된 경우에만 적용**되며, 이전 버전(v1~v4) 퍼즐에 소급 적용하지 않는다.

## 성능과 크기 제한
- 5×5, 10×10, 15×15, 20×20, 25×25는 독립 재검사로 유일해를 증명한 샘플을 확인했다.
- 30×30부터는 임의 셀 배치에서 유일해 판정에 시간이 오래 걸리며, 생성 실패율이 높을 수 있다. 50×50, 75×75, 100×100에서도 `unique`가 증명되지 않으면 **아무 결과도 저장하지 않는다**.
- 따라서 **모든 크기·시드에서 생성에 성공한다고 보장하지 않는다.** 25×25에서도 재시도 횟수에 따라 지연될 수 있다.
- 크기별 ‘쉬움/보통/어려움/전문가’ 이름은 여전히 메타데이터이며, 실제 추론 난이도와 일치한다는 뜻이 아니다.
- 유일해와 ‘추측 없이 논리만으로 풀 수 있음’은 다른 성질이다. v5는 정답 유일해만 보장한다.

## 멀티플레이 및 버전 호환
- 신규 퍼즐은 `designVersion:5`, 새 방의 `randomSpec.version:5`. v1~v4의 정답 생성 규칙을 바꾸지 않는다.
- 공개 시드가 있는 한 임의 플레이어가 답을 재현할 수 있어 치트 방지는 아니다.
- `random-puzzle-solver.js`는 현재 즐거움 평가 함수와 별개로 `countSolutions`를 제공한다. 생성기 v5에서는 풀이 기반 재미도 점수를 산출하지 않는다.
- Firebase `database.rules.json`의 v5 허용 규칙을 **운영 Firebase에 별도로 배포**해야 한다. GitHub 코드만 반영하면 대결·협동 방 생성은 정상 작동하지 않을 수 있다.

## 검사 및 근거

- 노노그램 해의 유일성은 가능한 해를 최대 2개 찾는 방식으로 검증할 수 있다. 탐색 예산 초과는 검증 실패로 처리한다.
