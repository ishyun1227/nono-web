# 랜덤 노노그램 생성 규칙 (2026-10-31)

## 사용
- 기본(네온) 홈의 **혼자 풀기**에서 크기(작음·중간·큼·거대)와 난이도(쉬움·보통·어려움·전문가)를 선택하고 **새 랜덤 퍼즐 생성**을 누릅니다.
- 각 크기 그룹에서 실제 크기를 무작위로 결정: 작음 5/10, 중간 15/20, 큼 25/30, 거대 50/75/100.
- 이미지나 지정된 정답 그림이 필요 없습니다. 무작위 다중 해상도 노이즈 패턴 → 채움 마스크 → 가로·세로 힌트로 변환합니다.
- 생성된 퍼즐은 기존 본게임 엔진, 키보드·모바일 컨트롤, 힌트, 저장/되돌리기, 이어서 풀기 UI를 사용합니다.
- **혼자 풀기 전용의 로컬 체험 퍼즐**입니다. 현재 Firebase 정답 검증이 없으므로 공식 포인트/공개 순위/실시간 대결·협동에는 포함하지 않습니다.

## 구조적 품질 필터
- 행과 열의 힌트가 동일한 생성 마스크에서 계산되므로 서로 모순되지 않습니다.
- 빈 행/열(0 힌트), 과소/과다 채움(28% 미만, 68% 초과), 과도한 고립점, 너무 단조로운 행 반복, 영역 편중, 낮은 행 다양성, 크기·난이도에 비해 너무 단순하거나 조각난 단서를 거절합니다.
- 난이도는 노이즈 공간 주파수, 칠한 칸 밀도, 행·열 단서 덩어리 수에 따라 **추정**합니다. 정식 풀이 엔진의 논리 연산 횟수로 검증한 난이도는 아닙니다.
- 구조적 점수 80점 이상만 수용하고 품질 기준 미달 시 후보를 다시 생성합니다. 한도 내에서 끝내 통과하지 못하면 낮은 점수의 퍼즐을 제공하는 대신 오류를 알립니다.
- **이 점수는 사람의 재미 점수가 아닙니다.** 퍼즐의 주관적 재미, 유일해, 추측 없는 논리 풀이 가능성을 보증하지 않습니다. 재미의 지속적인 개선에는 실제 플레이 평가·포기율·완주율이 필요합니다.

## 저장·운영 제한
- 최근 최대 100개 생성 퍼즐의 공개 힌트와 메타데이터만 동일 브라우저 localStorage에 보관합니다. 저장 용량이 가득 차거나 100개에 도달하면 사용자에게 실패를 알립니다. 기존 저장을 조용히 삭제하지 않습니다.
- 시작·이어하기 상태는 기존 `nono-web-puzzle-v1:<id>` 및 delta-undo/redo 저장 방식을 재사용합니다.
- 다른 기기에서는 로컬 생성 퍼즐 자체가 자동 복원되지 않습니다. 소셜 로그인 시 기존 진행 기록 동기화와 별도로 **동일 생성 힌트 동기화**가 필요합니다.
- 현재 마스크나 미리보기 정답 이미지는 저장/게시하지 않습니다. 완성 판정은 일반 엔진처럼 힌트 전체가 일치하는지 확인합니다. 중복해가 있더라도 힌트에 맞는 완성은 인정합니다.
- 배포: `tools/build.cjs`가 `random-puzzles.js`를 dist에 복사. GitHub main 푸시 후 Cloudflare 빌드 설정이 활성화된 경우 배포될 수 있으나, 실제 배포 결과는 별도 확인해야 합니다.

## 검사
- `node tests/random-puzzles.cjs`: 5·10·15·20·25·30·50·75·100에서 난이도 4개를 대상으로 품질 필터·힌트 합계·로컬 복원을 검증합니다.
- `npm run build`: Cloudflare용 정적 번들 파일 검증.
