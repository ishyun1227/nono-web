# 무작위 흑백 노노그램 10초 제한 풀이기 벤치마크

- **실행 일자:** 2026-11-06 (KST); **검증된 GitHub Actions:** https://github.com/ishyun1227/nono-web/actions/runs/42162647610
- **재현 코드:** https://github.com/ishyun1227/nono-web/blob/main/tests/benchmark-random-ten-seconds.mjs
- **테스트 데이터:** 5×5, 10×10, 15×15, 20×20, 25×25, 30×30, 50×50, 75×75, 100×100 각 3개씩 = 27개
- **난수 생성:** 각 칸을 독립적으로 xorshift32 시드 난수로 생성. 검은색 확률 35%/50%/65%; 이미지 템플릿·그림 도형·유일해 선별 **사용하지 않음**. 시드는 크기와 비율에서 결정되어 재현 가능함.
- **경쟁:** 12개 방식 × 27개 퍼즐 = **324회**, 각각 독립적인 Node 프로세스에서 최대 **10초** 제한. 유일해 검증 **27회**는 이와 별개로 CaDiCaL의 반례 SAT 탐색(최대 8초) 수행.
- **유일해 확인:** **unique 7, multiple 14, unknown 6**. `unknown`은 유일하지 않다는 뜻이 아니라 검증 시간·자원이 부족하다는 뜻임.
- **정답 인정:** 모든 칸이 힌트를 만족하는 완성해면 성공; 생성한 원본과 다른 완성해도 복수해 퍼즐에서는 유효. 부분 풀이·시간 초과·오류는 실패로 계상.
- **시간 지표:** 성공한 실행의 평균 solver elapsedMs (SAT CNF 인코딩·WASM 초기화 포함, 자식 프로세스 생성 제외). 성공 수가 다르면 평균만으로 비교 금지.
- **결과 제한:** 각 크기·비율당 **1개**, 즉 반복 실험이나 대규모 표본은 아님. 실행 환경의 부하·난수 표본에 영향을 받을 수 있음.

## 결과 해석과 제한

1. **가장 높은 완성률:** CaDiCaL 단독과 Adaptive→CaDiCaL 5개 변형 모두 22/27 성공(81.5%). 반면 Adaptive 단독은 7/27(25.9%). 이전의 규칙적인 그림 퍼즐보다 완전 무작위 그리드가 논리 풀이에 더 어려웠다.
2. **SAT 관련 평균 최단 시간:** Adaptive가 막힐 때 SAT로 넘기는 방식이 성공한 22개에서 평균 **582.7ms**, 90% **617.6ms**, 75% **632.9ms**, 50% **688.1ms**, 25% **733.2ms**, CaDiCaL 단독 **966.4ms**였다. 단, 90%/75% 등의 목표는 각각 11/27, 12/27에서만 실제 도달했다. 도달하지 못하면 현재 확정 상태 그대로 SAT로 넘겼다.
3. **100×100:** 모든 SAT 계열에서 1/3 성공. 65% 흑백 사례만 완료했고 35%·50%는 10초 제한 내에 완료되지 못함. 100×100의 유일해 여부는 3개 모두 `unknown`. 따라서 대형 랜덤 퍼즐을 서비스에 투입하기에는 현재 검증이 부족하다.
4. **기존 3개 결합의 병목:** 앞선 Nonogram-Maker의 패턴 열거가 10초를 소모하면 마지막 SAT로 넘어가지 못함. 단계별 시간 배정 없이 단순히 연결하면 불리할 수 있음.
5. **실서비스 권장:** 유일해 검증은 퍼즐 생성 단계에서 따로 수행하고, 플레이 단계에서는 Adaptive 우선 → 진전 없음 시 CaDiCaL로 전환. 다만 이것은 위 27개 데이터에 근거한 제한적인 권장일 뿐 모든 난수·난이도에서 최적이라는 증거는 없음.
6. **검증 공정성:** 난수 시드와 결과 hash를 각 JSONL 로그에 포함하고, 10초 초과는 완성으로 처리하지 않음. `elapsedMs`는 실행 내부 시간이며 `wallMs`는 프로세스 시작 포함.

각 크기별 원시 JSONL 결과는 Actions의 `nonogram-random-5`, `nonogram-random-10`, …, `nonogram-random-100` 아티팩트로 업로드되었고 30일 보존 설정임. 벤치마크/인코더를 갱신했으며, **실제 웹사이트 퍼즐 풀이 UI는 이번 작업에서 변경하지 않음**.
