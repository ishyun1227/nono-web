# 유일해 랜덤 퍼즐 5개 × 풀이기 상위 3개 비교 (2026-11-06)

## 실험 목적과 출처

이전의 **유일해만 추린 7개** 성적표에서 상위 3개 풀이 방식만 새로 생성한 퍼즐에 적용했다.

1. Adaptive: 새 논리 풀이기 단독
2. Adaptive full → CaDiCaL: 새 논리 풀이기를 끝까지 수행, 더 이상 확정할 수 없으면 SAT로 넘김
3. Adaptive 90% → CaDiCaL: 확정 칸이 최소 90%가 되면 SAT로 넘김

- GitHub Actions 실측: https://github.com/ishyun1227/nono-web/actions/runs/42164972788
- 벤치마크 코드: https://github.com/ishyun1227/nono-web/blob/main/tests/benchmark-five-unique.mjs
- **보관된 퍼즐 정답/행·열 힌트 5개:** https://github.com/ishyun1227/nono-web/blob/main/tests/fixtures/five-unique-random-20261106.json
- 각 크기에서 각 칸을 독립적인 시드 난수로 생성. 검은색 확률 65%. 행·열 힌트는 답안에서 산출.
- 각 크기별 첫 후보(시도 번호 0)가 전부 유일해 판정을 통과하였으며, 풀이 시간이나 난이도로 선별하지 않았다.
- **유일해 증명 방법:** 알려진 생성 답안을 배제하는 SAT 절을 더한 후 CaDiCaL로 UNSAT 검증. 5개 모두 `unique` 판정. 모든 퍼즐은 원본 조건을 충족하는 해를 보유.
- 풀이기별 **5번 반복**, 독립 Node 실행에서 최대 **10초**. 전체 **75회** 중 **75회 완성**.
- 시간은 각 프로세스 내 계산 시간 `elapsedMs`; 별도 자식 프로세스 실행 준비시간 제외.
- 아래 속도는 **5회 중앙값**. 미세 차이는 측정 오차 가능성이 있으므로 반복 없는 절대 승자로 해석하지 않는다.

## 해석

- **Adaptive 단독 25/25, Adaptive→필요시 SAT 25/25, Adaptive 90%→SAT 25/25.**
- 이 5개 퍼즐은 Adaptive만으로 완성됨. 따라서 Adaptive→필요시 SAT는 **CaDiCaL을 호출한 횟수 0/25**이고, Adaptive 단독과 실제로 같은 알고리즘 경로를 실행했다. 1~2ms 이하의 차이는 별도의 우수성 증거가 아니다.
- Adaptive 90%→SAT는 각 퍼즐에서 90% 이상 채워진 뒤 SAT를 호출한 횟수 **25/25**. SAT CNF 생성·WASM 초기화의 고정 비용 때문에 이 표본에서는 느렸다.
- 이 표본에 한정하면 **Adaptive 우선, 막히면 CaDiCaL**이 합리적이다. 단 **논리가 중간에 멈추는 유일해 퍼즐**의 실제 SAT 보완 효과는 시험하지 못했다.
- 다섯 퍼즐 모두 검은색 65%의 무작위 샘플이므로 다양한 밀도, 50~100 크기, 해설이 어려운 생성 퍼즐로 일반화할 수 없다.
- 유일해 5개는 GitHub에 보관했지만 **라이브 웹사이트의 퍼즐 카탈로그에는 등록하지 않았다**.
