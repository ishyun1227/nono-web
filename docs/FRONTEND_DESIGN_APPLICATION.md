## 사용자 과업과 위계
사용자의 목적은 퍼즐을 선택하고 즉시 플레이하는 것이다. 기본 홈페이지는 일반 랜딩 페이지나 SaaS 대시보드가 아니라 노노그램 게임의 작업대다. 기존 대결, 협동, 기록, 이어서 풀기, 미션, 출석 및 사이드 영역은 동작을 유지한다. 무엇보다 실제 퍼즐 보드와 모바일 조작 기능에 시각 개편이 침범하지 않아야 한다.

## 스킬 1차 제안 → 자기검토 → 수정
초기 안은 밝은 배경, 녹색 강조, 같은 크기의 둥근 카드들을 정리하는 방향이었다. 이는 색만 바뀐 AI 템플릿에 가깝다는 피드백과 스킬의 경고에 해당하므로 그것만으로는 불합격이라고 판단했다.

수정한 방향은 **퍼즐 선택 작업대 + 진행 중인 세션 색인**이다. 퍼즐 필터/목록은 독립된 선택 영역으로, 이어서 풀기는 카드 갤러리가 아닌 조밀한 정보 목록으로 구성한다. 패턴은 노노그램의 실제 행·열 격자를 참조하는 범위에서만 사용하고, 가짜 게임 데이터나 의미 없는 번호 장식을 만들지 않는다.

## 레이아웃 원칙

데스크톱 (기존 양쪽 레일과 화면맞춤 구조 유지):

```text
┌──────────────────────────── 내비게이션 ────────────────────────────┐
│ 최근 클리어 │  퍼즐 선택 작업대   │ 이어서 풀기 세션 색인 │ 광고 자리 │
│            │  ┌──────┬────────┐ │  2열 상태/진행도 목록  │           │
│            │  │크기/ │ 퍼즐   │ │                      │           │
│            │  │난이도│ 번호   │ │                      │           │
│            │  └──────┴────────┘ │                      │           │
│            │  오늘의 미션   /   출석 보상                │           │
└───────────────────────────────────────────────────────────────────┘
```

- 데스크톱 너비 1231px 이상에서 좌측 필터/우측 퍼즐 목록으로 배치.
- 981–1230px에서는 좁은 본문 폭을 고려해 두 선택 영역을 세로로 놓고 버튼은 촘촘한 격자로 정렬.
- 태블릿·모바일은 기존 테스트된 레이아웃을 보존하며 터치 대상과 퍼즐 조작 영역을 침범하지 않음.
- 프리미엄 월드의 고유한 레이아웃은 적용 대상이 아님.

## 변경 범위 및 검증
- 원본 디자인 스킬과 라이선스를 로컬 에이전트 스킬 디렉터리에 설치.
- `quiet-grid.css`에서 기본 홈의 CSS 그리드·크기/난이도 선택 배치·퍼즐 목록·이어 풀기 목록의 구조를 변경.
- `AGENTS.md`에 스킬 적용 및 사용자 과업 우선 원칙 추가.
- CSS 괄호/인용부호 균형 검사 통과.
- **미확인:** 실제 브라우저 스크린샷, 빌드/런타임 기능 테스트, Cloudflare 배포 완료. 실사용 검증 전에는 완성/검증 완료라고 주장하지 않는다.

## 후속 검증 체크
1. 데스크톱 1440×900 / 1280×720 / 1024×768에서 모든 버튼 표시와 줄바꿈 검증.
2. 모바일 390×844 / 360×800에서 홈 화면 접근성과 플레이 화면의 스크롤/패드 겹침 여부 확인.
3. 4개 모드와 난이도 선택, 새 랜덤 퍼즐 생성, 이어서 풀기, 미션·출석, 테마 전환 테스트.
4. 완료된 화면을 시각적으로 검토하고 기능 결함이 있으면 백업 브랜치 기준으로 부분 복원.
