# NONO 기본 화면 구조 개편 — 2026-11-12

## 변경과 보존 범위

기본 테마의 실제 메뉴를 왼쪽 탐색 영역으로 옮기고, 퍼즐 선택 → 시작 → 이어 풀기를 중앙에 배치했다. 미션·출석·최근 클리어는 별도 보조 영역, 광고는 중앙 하단의 낮은 우선순위 레일로 정리했다. 작은 화면에서는 메뉴가 상단으로 이동하고 보조 영역은 퍼즐 선택 뒤에 이어진다. 가짜 퍼즐·기록·사용자 수는 추가하지 않았다.

HTML의 nav/support aside와 테마 복원 위치를 새로 구성했으며, 기존 선택·저장·Firebase 이벤트를 그대로 연결했다. 새 홈페이지 CSS에는 `!important`를 추가하지 않았다. 종전 홈페이지 스타일은 플레이 화면에 한정해 격리했고, 기존 여러 테마의 이동/복원 경로를 유지했다. 게임 엔진·정답·Firebase 규칙은 변경하지 않았다.

기본 시스템은 Taste가 제시한 black-crimson 팔레트와 Epilogue 서체를 사용한다. 한국어는 기기 한글 글꼴을 사용하며, 서체 파일과 OFL 라이선스를 함께 배포한다. 계정은 헤더와 온라인 기능 진입에서 계속 이용할 수 있고, 첫 접속 팝업은 퍼즐 선택을 가리지 않도록 자동 표시를 없앴다.

## 최초 화면과 모바일 수정

- 기존 7초 타이머가 UI 구성 완료 여부와 무관하게 화면을 공개하던 경로를 제거했다. 동기 UI 모듈 완료 이벤트 다음 프레임에 공개한다. 7초 이후에는 로딩 안내만 바뀐다.
- 배포 HTML의 모든 로컬 CSS/JS URL을 파일 내용 해시로 갱신해 구버전 구조 스크립트·스타일이 섞이는 캐시 문제를 방지한다.
- 도움 버튼에 서로 다른 컨트롤 파일이 위/아래 위치를 동시에 지정하던 규칙을 제거했다. 도움·확대 버튼은 퍼즐 아래 전용 줄을 사용한다.
- 모바일 게임의 fixed 쌓임 맥락 때문에 뒤로 가기/제목이 상단 바 뒤에 가려지던 문제를 수정했다.
- 패드를 접은 상태에도 도구 줄 공간을 확보한다. 확대 후 퍼즐 내부 이동은 기존 기능이며, 맞춤 화면의 문서 스크롤과 구분한다.
- Windows 체크아웃의 CRLF 때문에 정상 카탈로그 빌드가 실패하던 비교를 줄바꿈 정규화로 수정했다.
