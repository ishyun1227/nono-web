## 제한 사항
- AI 원본 그림의 실제 재생성은 이미지 생성 도구를 지원하는 실행 환경에서 에이전트가 수행해야 함. ZIP 안의 Python 프로그램이 혼자 이미지 모델을 호출하지는 않음.
- 정답 유일성 검사에서 `unknown`은 검증 실패/시간 초과이며 합격이 아님.
- 픽셀 유사도 점수만으로 이빨·눈 등 의미적 특징의 보존을 입증할 수 없음.
- 사람의 재미 자체는 자동 증명 불가능함.
- 모바일 ChatGPT에 자동 설치된 상태가 아니라 **설치·배포용 스킬 파일 묶음**임.
