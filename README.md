# NONO — 노노그램 웹사이트

간소화한 NONO 웹 버전의 첫 공개 배포용 저장소입니다.

## Cloudflare Workers 배포 설정

1. Cloudflare 대시보드에서 **Workers & Pages → nono-web → Settings → Builds**로 이동합니다.
2. GitHub 저장소 `ishyun1227/nono-web`을 선택합니다.
3. 아래 값을 지정하고 배포합니다.

| 설정 | 값 |
| --- | --- |
| Production branch | main |
| Build command | `npm run build` |
| Deploy command | `npx wrangler deploy` |
| Preview deploy command | `npx wrangler preview` |
| Assets directory | `dist` (`wrangler.jsonc`에 지정) |
| Root directory | 기본값/비움 |

UI는 `index.html`, 사용자 설정은 `settings.js`, 공개 Firebase 웹 설정은 `firebase-config.js`에 있습니다. 저가형 색상 테마는 `themes.css`·`theme-extras.css`에서, 월드 테마는 `premium-themes.css`·`theme-extras.css` 및 직접 제작한 `assets/*-scene.svg`에서 관리합니다. 상점·미리보기는 `themes.js`, 월드별 실제 퍼즐 선택 화면은 `theme-world-ui.js`에서 관리합니다. 빌드는 이 파일들과 기존 웹 UI·Firebase 웹 설정만 `dist/`로 복사합니다. `node_modules`와 테스트·서버 규칙 파일은 웹에 배포하지 않습니다.

프리미엄 월드 테마는 **공통 퍼즐 엔진·Firebase 데이터를 유지한 채 홈페이지·메뉴·모드 카드·퍼즐판·설정창의 외형, 장식, 글꼴 및 일부 레이아웃**을 대폭 변경합니다. 월드 전용 CTA·실제 퍼즐 선택 도감·테마 상점 안내도 포함됩니다. 이미지 콘셉트를 참고했으나 AI 시안과 픽셀 단위로 동일한 사진형 일러스트는 아닙니다. 특정 동물 캐릭터를 모든 월드에 강제로 사용하지 않습니다.

**포인트 적립, 서버 측 구매·소유 검증, 영구 잠금 해제는 아직 구현되지 않았습니다.** 테마 가격은 **확정 전 예시**입니다. 구매 전 테마는 브라우저 탭 단위 임시 무료 체험이며 탭을 닫으면 기본 테마로 돌아갑니다. 상품을 구매했다거나 포인트가 차감되었다고 표시하지 않습니다.

## 신비로운 도서관: 3차 전체 UI 재설계 (2026-10-22)

이전의 저해상도 스크린샷 자르기 방식은 제거했습니다. **사용자의 레퍼런스 이미지를 새로 생성하거나 잘라 재사용하지 않고**, 도서관 장면과 네 가지 모드 그림을 독립적인 SVG 벡터 장식으로 새로 제작했습니다. 확대해도 글자·아이콘·UI 테두리는 웹 컴포넌트로 선명하게 표시됩니다.

- `assets/library-world.svg`: 책장, 아치형 천문 창문, 매달린 조명, 별자리 구체 등으로 이루어진 신규 벡터 배경.
- `assets/library-mode-{practice,race,coop,record}.svg`: 플레이 방식별 다른 고해상도 삽화.
- `library-precision.css`: 홈페이지, 게임 메뉴, 카드 레이아웃, 양피지형 실제 퍼즐판, 모바일 레이아웃을 포함한 프리미엄 전체 재디자인. 홈·퍼즐 화면 구조는 기존 색상 테마와 달라집니다.
- `library-ui.js`: 실제 모드 전환에 연결되는 탐색 메뉴, 게임에서 실시간 진행률을 보여 주는 목표 카드.
- **허위 데이터 없음:** 랭킹·채팅·포인트 구매는 실제 구현된 범위에서만 노출. 가짜 사용자 수, 조작된 대화, 존재하지 않는 모드는 추가하지 않음.
- 기존 퍼즐 엔진·Firebase 규칙·키보드 조작은 그대로 유지하며 디자인만 독립적으로 적용합니다.

참고 이미지는 분위기와 레이아웃 아이디어의 참고자료이지 배경 스크린샷으로 사용하지 않습니다. SVG 벡터 특성상 참고 이미지의 사실적인 일러스트와 픽셀 단위로 동일하지는 않습니다.

## 프리미엄 정령의 숲 — 독립 웹사이트 구조 (2026-10-22)

참고 분위기: [Lumen Grove 공식 웹사이트](https://points.gs/)의 밤 숲/금빛 정령/라벤더 수목 일러스트. **해당 게임의 이미지·UI 소스를 직접 복사하거나 재배포하지 않았습니다.**

- `forest-world.js`: 기존 `#home-view`의 홈화면을 사용하지 않고 **별도 `#forest-experience` 페이지**를 생성합니다. 전용 네비게이션·히어로·독립 모드 선택·모험 준비·도감이 있으며, 실제 게임의 `#setup`, `#game`, `#toast` 노드를 별도 페이지로 이동합니다. 테마 해제 시 정확히 원래 위치로 복원합니다.
- `forest-world.css`: 화면 전체를 사용하는 달빛 숲, 별개의 타이포/모드 카드/퍼즐 HUD/모바일 레이아웃. 색상만 바꾸는 값싼 테마와 구조적으로 다릅니다.
- `assets/forest-world.svg`: 금빛 식물·라벤더 잎 수목·숲 배경을 **새로운 자체 SVG 코드로 제작**. 외부 유료 게임 자산을 복사하지 않았습니다.
- 전용 카드 4종과 실제 퍼즐 선택 도감은 기존 모드 버튼과 퍼즐 선택을 호출하여 실행되며, 키보드·자동 저장·Firebase·힌트는 원본 엔진을 재사용합니다.
- 주의: 프리미엄 테마 구매·포인트 차감/영구 소유는 아직 미구현으로 기존 체험 정책을 유지합니다.
- 테스트: `tests/smoke.cjs`에 숲 전용 DOM, 모드 선택, 키보드 입력, 실제 보드와 기본 테마 복귀, 모바일 렌더링 테스트 추가.

## 프리미엄 테마 — 던전 터미널 (CRT Desktop)

사용자가 제공한 1990년대 녹색 CRT 게임형 데스크톱 화면을 **시각적 참고자료로만 활용**해 제작한 독립 웹 UI입니다. 원본 게임의 이미지·아이콘·프로그램 코드는 복사하지 않았습니다.

- **새 화면 구조:** [terminal-world.js](terminal-world.js)는 별도 `#terminal-experience`를 구성하며, 기존 NONO 홈 화면을 재사용하지 않습니다. 왼쪽 Player/Properties, 가운데 Dungeon Explorer, 오른쪽 Stats/Inventory/Tools, 아래 MENU 작업표시줄을 새 HTML로 제작했습니다.
- **스타일:** [terminal-world.css](terminal-world.css)는 형광 연두 CRT, 검은 4~6px 창 테두리, DOS 폰트, 스캔라인·화면 비네팅, 녹색 화살표/아이템 카드를 구현합니다.
- **자체 그래픽:** [terminal-wallpaper.svg](assets/terminal-wallpaper.svg)로 던전 지도 느낌의 손그림 배경 제작. 확대해도 깨지지 않습니다.
- **실제 기능:** 별도 창은 기존 모드 버튼, 퍼즐 선택, 실제 게임판, 타이머, 진행률, 조작도구, 설정창, Firebase 멀티에 직접 연결됩니다. 테마를 바꾸면 기존 게임 노드를 원래 위치로 복원합니다.
- **가짜 RPG 기능 없음:** Player 창에는 실제 입력한 이름과 게임 모드, 진행률을 표시합니다. Inventory는 존재하는 퍼즐 목록이며 포인트·코인·전투 스탯을 허위로 출력하지 않습니다. 현재 표시되는 테마 가격 6,500 P는 결제/소유 기능이 없는 **예정값**입니다.
- PC / 모바일 반응형이며 `tests/smoke.cjs`에 페이지 구조, 키보드·모드 연동·테마 복귀 검사를 추가했습니다.

## 현재 사용 가능 범위

- 싱글플레이: 실행 가능
- 키보드: 방향키, Space, X, Backspace, Ctrl+Z/Y
- 실시간 대결 및 협동: Firebase 익명 인증과 Realtime Database 사용
- 온라인 기록 경쟁: 서버 검증과 퍼즐별 최고 기록 순위표

Firebase 연결값이 비어 있으면 오프라인 체험으로 실행됩니다. 익명 인증, 서버 보안 규칙, 에뮬레이터 테스트가 포함되어 있으며 운영 연결과 테스트 방법은 [FIREBASE.md](FIREBASE.md)에 있습니다. Firebase 프로젝트 생성·규칙 배포·웹 설정 반영이 완료되어야 온라인 기능을 사용할 수 있습니다.

## 주의

정적 웹사이트 배포 비용과 Firebase 등 실시간 백엔드 이용 요금은 별개입니다. 현재 저장소는 공개(Public) 상태이므로 실제 비밀키나 개인 정보를 커밋하지 마세요.

## 공개 대결·협동 로비 (2026-10-23)

- 대결과 협동 모드에서 빠른 매칭, 실제 공개 방 목록, 방 참가, 공개/비공개 방 만들기를 지원합니다.
- 빠른 매칭은 같은 모드와 퍼즐을 우선 찾으며, 없으면 공개 방을 만듭니다. 빠른 대결 호스트는 두 번째 플레이어가 오면 자동 시작합니다.
- Firebase RTDB `publicRooms`는 최근 30건까지 제한해 조회하며, 참가자 숫자는 기존 `rooms/{code}/players`를 참조합니다.
- 대결 시작, 협동 완료 및 방장 퇴장 또는 연결 종료 시 공개 목록에서 제거합니다. 익명 계정, 초대 코드 방식과 최대 4명 제한은 유지됩니다.
- **중요:** 실제 Firebase 서버에 `database.rules.json`을 별도로 배포해야 공개 목록과 빠른 매칭이 동작합니다. GitHub에 코드를 올리는 것만으로 DB 규칙이 적용되지 않습니다.

## 30×30 복셀 브레인롯 퍼즐 (2026-10-23)

원본 VOX 모델(토스티노 크라비노)을 정면·측면·윗면 세 방향에서 투영한 30×30 노노그램을 운영 사이트의 혼자 풀기 모드에 추가했습니다. 30×30을 선택하고 01·02·03 중에서 고릅니다. 정답 이미지는 퍼즐 선택 화면에 노출하지 않습니다.

신규 퍼즐은 **현재 혼자 풀기 전용**입니다. Firebase 운영 규칙과 비공개 서버 정답은 기존 5×5·10×10 세 퍼즐만 지원하며, 30×30 대결·협동·기록 모드는 이를 확장·배포하기 전까지 비활성화합니다. 별도 웹사이트는 생성하거나 배포하지 않습니다.
